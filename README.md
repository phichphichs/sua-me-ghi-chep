# Sữa Mẹ Ghi Chép

Web app (PWA) ghi lượng sữa mẹ hút và sữa bé uống theo cữ, nhập bằng giọng nói tiếng Việt, có biểu đồ. Dữ liệu chỉ lưu trên thiết bị (localStorage).

- Ghi âm → chữ: Web Speech API của trình duyệt (`vi-VN`).
- Chữ → dữ liệu: `parser.js` (bộ luật, không dùng AI).
- Trên iPhone: mở link bằng Safari → Chia sẻ → Thêm vào MH chính.
